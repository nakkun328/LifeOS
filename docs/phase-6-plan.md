# Phase 6 計画：残りの機能

`LIFE_OS_PLAN_3.md` に沿って、Wishlist → English Words → Journal → Insights の順に作る。
1つ終わるごとに、テスト・コミット・push。

## 守ること（本番稼働中）
- 既存のマイグレーションは書き換えない。機能ごとに新しいマイグレーションを足す（0004 Wishlist、0005 English Words、0006 Journal。Insights はテーブルを足さない）。
- どれも、新しいテーブルを足すだけ。既存の列・行には触れない。**既存データが入った状態の PostgreSQL に流して**、データが残ることを確認する。
- 適用手順は `SETUP.md` に書く（0003 のあとに、番号順）。

## 共通
- 入力は最小限（必須は1〜2項目）。主要操作は Today から2タップ以内。
- 責める言葉は使わない。比べる相手は過去の自分。
- 外部の有料 API は使わない（文章はテンプレートで組み立てる）。
- データが足りないときは、「あと何件たまると表示されるか」を出す。
- 集計・判定は純粋関数に切り出して、テストを書く。

## 順番
1. **Wishlist**（Life > Wishlist）：名前だけで登録。優先度順、購入済みは下。1タップで購入済み。お金の管理とは連動しない。
2. **English Words**（Study > 英単語）：まとめて登録、2択の復習（間隔は正解が続くほど延びる）、テスト期限の優先、Today に件数。
3. **Journal**（Life > 日記）：テンプレートで自動生成。手で編集した日記は上書きしない。
4. **Insights**（5つ目のタブ）：今週と先週、勉強（時間帯・セッションの長さ × 効率）、睡眠と Digital。最低件数を決め、件数を添える。Today に1件だけ。
5. **Discord**：`/words`、`/journal`。
6. 仕上げ：`SETUP.md`、`PROGRESS.md`、`DECISIONS.md`。
