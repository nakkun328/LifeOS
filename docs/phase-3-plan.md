# Phase 3 計画：Tasks と 一言ログ

## 方針
- Phase 2 の構成（`Db` インターフェース + ハンドラ + 純粋関数）をそのまま使う。
- 入力は最小限：課題は「名前＋期限」、ログは「1行＋タグ」。

## 作るもの
1. `supabase/migrations/0002_tasks_logs.sql`：tasks / logs
2. API：tasks（一覧・追加・進捗変更）、logs（一覧・追加）
3. 純粋関数（`web/src/lib/tasks.ts`）：残り日数、期限順の並べ替え、Today 用の抽出
4. 画面：
   - Today：期限が近い課題（数件・残り日数つき）、一言ログの入力欄と今日のログ
   - `/tasks`：課題の一覧・追加・進捗の1タップ変更（未着手 → 途中 → 完了）
   - `/logs`：日付ごとの一覧
5. 部活：Study と同じタイマーで、種別を「勉強 / 部活」に切り替える。集計は勉強と分けて表示（Phase 2 で集計は実装済み）

## 表現
- 期限切れは責めない：「期限から2日（落ち着いて、できるところから）」
- 残り日数は「あと3日」「今日が期限」

## 完了条件
- 課題とログを、Webから1〜2操作で記録できる
- Today に課題の残り日数と今日のログが出る
