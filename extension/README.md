# Night Guard（Chrome拡張）

Life OS Phase 1。夜になると YouTube・X・Instagram を段階的に制限する Manifest V3 拡張です。
完全なブロックではなく「一手間かかる壁」として、開こうとした瞬間に「今寝たら何時間寝られるか」を見せます。
バックエンドは不要で、拡張の中だけで動きます。

## 仕様

| 時刻（初期値） | 動作 |
|---|---|
| 22:45 | 「寝る準備」の通知（23:15 を過ぎていたら出さない） |
| 23:15 | YouTube Shorts・X（x.com / twitter.com）・Instagram を制限 |
| 23:30 | YouTube 全体（ホーム・検索・チャンネル・動画）も制限 |
| 06:00 | 自動解除 |

- 時刻はすべて設定画面で変更できます。日付をまたぐ時間帯（23:15〜翌06:00）に対応しています。
- 段階が切り替わった瞬間に、**すでに開いているタブも**ブロック画面へ差し替えます。
- 一時解除は **サイト別**（YouTube / X / Instagram）。YouTube を解除しても X・Instagram は開きません。
- 一時解除：理由を一言入力 → 待ち時間（初期30秒）→ 解除時間（初期10分）だけ開く。期限が切れたら再び制限します。
- 除外：`music.youtube.com` は常に対象外。設定で許可した再生リスト（URL の `list=`）の `/watch`・`/playlist` は通します。
- 制限中（23:15〜06:00）は設定画面が表示のみになり、編集できません。
- 制限・解除の出来事は `chrome.storage.local` に保存します（時刻・種別・サイト・解除理由）。同一タブ・同一サイトの制限は60秒以内なら1件にまとめます。

### 時刻の扱い（壊れにくさ）
制限するかどうかは **常に現在時刻から判定**します。アラームは「判定し直すきっかけ」でしかないので、遅れても発火しなくても結果は変わりません。
段階の切り替え時刻・解除の期限切れ・1分ごとの保険アラームのほか、ブラウザ起動時にも開いているタブを判定し直します。

## ビルドとテスト

```sh
cd extension
npm install
npm test            # 単体テスト（判定ロジック）
npm run typecheck
npm run build       # → dist/      通常ビルド
npm run build:dev   # → dist-dev/  開発ビルド（時刻固定のデバッグ機能つき）
```

ビルドツールは esbuild です。MV3 は background・ブロック画面・ポップアップ・設定画面を別々のバンドルにする必要があり、
esbuild なら設定ほぼ不要で一瞬で終わります。テストは vitest（TypeScript をそのまま実行できます）。

## Chrome への読み込み

1. `npm run build` を実行します（動作確認だけなら次の `build:dev` を使います）。
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパー モード** をオンにします。
3. **パッケージ化されていない拡張機能を読み込む** を押し、`extension/dist`（開発ビルドなら `extension/dist-dev`）を選びます。
4. ツールバーのパズルアイコンから Night Guard をピン留めすると、ポップアップをすぐ開けます。

コードを変えたら再ビルドして、拡張機能のページで更新ボタンを押してください。

## 動作確認（夜まで待たない方法）

**開発ビルド**（`npm run build:dev` → `extension/dist-dev` を読み込む）には、仮想の現在時刻を設定できる機能があります。
通常ビルドにはこの機能のコードが含まれません（制限中に時刻を書き換えて素通りするのを防ぐため）。

1. 設定画面（ポップアップの「設定を開く」）の一番下にある「開発用：仮想の現在時刻」に時刻を入れ、「この時刻にする」を押します。
   以降は実時間どおりに進みます。「実時刻に戻す」で解除できます。
2. 次のように確認します。

| 仮想時刻 | 確認すること |
|---|---|
| 22:44 → 22:45 | 22:45 になると「寝る準備」の通知が出る。ポップアップの段階が「寝る準備の時間」になる |
| 23:14（X と YouTube Shorts を開いたまま）→ 23:15 | 開いているタブが自動でブロック画面に切り替わる。YouTube の通常動画はまだ見られる |
| 23:29 → 23:30 | 開いている YouTube（ホーム・検索・チャンネル）もブロック画面になる |
| 23:31 | ブロック画面の「いま眠れば ◯時間◯分」が1秒ごとに動く。設定画面が表示のみ（編集不可）になる |
| 23:31 | 「どうしても少しだけ開きたいとき」を開き、理由を入れて待つ → 元のページに戻る。ポップアップの「今夜の解除回数」が増える |
| 解除後 | 解除したサイトだけ開ける（YouTube を解除しても X は開けない）。解除時間が切れると再び制限される |
| 23:31 | `music.youtube.com` は開ける。設定で許可した再生リストの動画も開ける |
| 05:59 → 06:00 | 06:00 を過ぎるとブロック画面から元のページへ自動で戻る。ポップアップは「制限なし」 |

- 記録の確認：`chrome://extensions` → Night Guard の「service worker」から開発者ツールを開き、Console で
  `(await chrome.storage.local.get('events')).events` を実行します。
- 設定画面は制限中は編集できないため、時刻設定を変えたいときは仮想時刻を昼間（例 12:00）にしてから行います。
- 待ち時間や解除時間を試すときは、設定画面で待ち時間を `3` 秒などにしておくと速く確認できます。

## 許可する再生リスト
設定画面に、再生リストの URL か ID（URL の `list=` の値）を1行に1つ入れます。
チャンネル単位の許可は、今回は入れていません（Phase 1 を軽く保つため。必要になったら後で追加します）。

## 権限
- `storage` / `alarms` / `notifications` / `webNavigation`
- `host_permissions`：`youtube.com` / `x.com` / `twitter.com` / `instagram.com`（https のみ）
- `tabs` 権限は不要です（ホスト権限の範囲でタブの URL を扱えます）。

## ファイル構成
```
extension/
  build.mjs               esbuild + 静的ファイル + アイコン生成
  static/                 manifest.json、各HTML、CSS
  src/
    core/                 chrome API に依存しない純粋関数（テスト対象）
      stage.ts            段階判定・次の切り替え時刻
      match.ts            URL の分類・制限するかの判定
      sleep.ts            「今寝れば」の計算
      settings.ts         初期値・検証・編集ロック
      night.ts / dedupe.ts / time.ts / types.ts
    storage/
      eventLog.ts         記録は必ずここを通る（Phase 2 で送信先を足す）
      settings.ts / unlock.ts
    clock.ts              現在時刻の取得（開発ビルドのみ仮想時刻）
    background.ts         遷移の監視・アラーム・通知
    blocked.ts / popup.ts / options.ts / debugPanel.ts
```
